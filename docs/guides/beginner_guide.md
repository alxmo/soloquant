# 📖 零基础小白使用指南

> **你不需要任何金融知识，会用大白话跟系统聊天就行！**

---

## 一、启动系统

打开终端（命令行），进入项目目录，输入：

```bash
python main.py
```

你会看到一个欢迎界面，然后进入**对话模式**。直接用大白话输入你的需求即可。

> 💡 如果想用数字菜单操作，可以输入 `python main.py menu`

---

## 二、最简单的用法：一句话搞定

启动后，你可以直接跟系统聊天。以下是几个最常用的场景：

### 🔥 场景1：帮我选股票（最常用！）

直接说大白话：
```
💬 你: 帮我选5支10美元的潜力股
💬 你: 选3只20到50美元的科技股
💬 你: 推荐几只便宜的股票
```

系统会自动扫描全市场，筛选出符合条件的股票，并用大白话解释每只股票为什么值得关注。

### 🔥 场景2：看看今天市场有什么机会

```
💬 你: 帮我看看今天有什么机会
💬 你: 扫描一下市场新闻
💬 你: 最近有什么热点
```

系统会自动抓取市场新闻和数据，告诉你哪些板块/股票值得关注。

### 🔥 场景3：帮我生成交易策略

```
💬 你: 帮我生成一个交易策略
💬 你: 为 AAPL 和 MSFT 创建策略
```

系统会用 AI 自动分析股票，生成一套完整的交易计划（什么时候买、买多少、什么时候卖）。

### 🔥 场景4：回测（用历史数据验证策略好不好）

```
💬 你: 回测一下策略
💬 你: 测试策略的历史表现
```

系统会用过去1年的数据模拟运行你的策略，告诉你：
- **每年平均赚多少**（年化收益率）
- **最惨的时候亏多少**（最大回撤）
- **赚钱的交易占多少比例**（胜率）

### 🔥 场景5：执行交易（模拟盘，不用真钱！）

```
💬 你: 执行交易
💬 你: 用模拟盘下单
```

⚠️ **放心**：系统默认使用**模拟盘（Paper Trading）**，不会动你的真钱！
它会在 Alpaca 平台上模拟下单，让你看到"如果真的买了会怎样"。

### 🔥 场景6：查看持仓和盈亏

```
💬 你: 查看持仓
💬 你: 今天的交易日报
💬 你: 账户怎么样了
```

系统会告诉你当前持有哪些股票、赚了还是亏了、风险状况如何。

### 🔥 场景7：一键全自动（最省事！）

```
💬 你: 一键全自动
💬 你: 帮我搞定全流程
```

系统会自动完成全部步骤：**选股 → 生成策略 → 回测验证 → 执行交易 → 监控持仓**。
你只需要等几分钟，然后看报告就行。

### 🚨 紧急情况：全部卖出

```
💬 你: 紧急清仓
💬 你: 全部卖出
```

如果觉得情况不对，一句话就能清空所有持仓。

## 四、其他实用命令

| 命令 | 作用 |
|------|------|
| `python main.py status` | 查看系统当前状态 |
| `python main.py health` | 快速健康检查（数据源/交易连接是否正常） |

| `python main.py realtime AAPL,MSFT` | 实时看盘（WebSocket 推送） |

## 五、系统会自动帮你翻译"术语"

你不需要懂任何金融术语。当系统提到专业词汇时，会自动用大白话解释，比如：

| 专业术语 | 系统会翻译成 |
|---------|------------|
| 年化收益 | 每年平均赚多少 |
| 最大回撤 | 最惨的时候亏多少 |
| 夏普比率 | 风险调整后的收益（越高越好） |
| 胜率 | 赚钱的交易占多少比例 |
| 仓位 | 一只股票占总资金的比例 |
| 止损 | 亏到一定程度自动卖出 |
| Paper Trading | 模拟盘（不用真钱） |

## 七、常见问题

### Q: 我需要配置什么才能用？
A: 在 `.env` 文件中配置以下 API Key（都是免费的）：
- `ALPACA_API_KEY` + `ALPACA_SECRET_KEY` → 模拟交易（免费注册：alpaca.markets）
- `FINNHUB_API_KEY` → 市场数据（免费注册：finnhub.io）
- 配好后运行 `python main.py health` 检查是否正常

### Q: 会用到我的真钱吗？
A: **不会！** 系统默认使用 Alpaca 的模拟盘（Paper Trading），所有交易都是模拟的。

### Q: 我不懂股票，能看懂系统的输出吗？
A: 能！系统专门设计了一个"通俗解读引擎"，所有专业术语都会翻译成大白话。

### Q: 系统的分析靠谱吗？
A: 系统使用微软 Qlib 框架 + LightGBM 机器学习模型进行量化分析，所有分析**仅供参考，不构成投资建议**。

### Q: 如果输入的话系统听不懂怎么办？
A: 直接输入"帮助"，系统会列出所有它能做的事。
