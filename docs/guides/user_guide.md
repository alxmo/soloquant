## 1. 系统简介

### 1.1 这是什么？

一个面向金融小白的 AI 全自动美股量化交易系统。你只需要用大白话告诉它你想做什么，它会自动完成：

- 🔍 **智能选股** — "帮我选5支10美元的潜力股"
- 📊 **市场调研** — 扫描新闻、分析情绪、发现热点
- 📈 **策略生成** — 自动搜索因子、训练模型、生成交易信号
- 🧪 **回测验证** — 历史数据验证策略效果，A/B/C/D 评级
- 💰 **模拟交易** — Alpaca Paper Trading 模拟下单
- 🛡️ **风控保护** — 7条风控规则，止损止盈自动执行
- 📋 **持仓监控** — 实时跟踪盈亏，异常告警

### 1.2 技术栈

| 组件 | 技术 | 用途 |
|------|------|------|
| AI 编排 | 多 Agent 架构 | Agent 协作、工作流、自然语言交互 |
| 量化引擎 | Microsoft Qlib | 因子挖掘、模型训练、回测 |
| 数据采集 | AKShare | 美股行情数据 |
| 交易执行 | Alpaca API | 美股模拟交易 |
| 金融数据 | Finnhub API | 新闻、情绪、基本面 |
| LLM 对话 | OpenAI 兼容 API | 意图识别、回复生成、多轮对话 |
| UI | Streamlit | 可视化仪表盘 |

### 1.3 系统架构

```
用户交互层    自然语言对话 / Streamlit 仪表盘 / 通知推送
    │
Agent 编排层  Research → Strategy → Backtest → Execution → Monitor
    │
量化引擎层    因子搜索 → 模型训练 → 信号生成 → 回测引擎
    │
数据层        AKShare(行情) + Finnhub(新闻/基本面) + Alpaca(账户)
    │
交易执行层    下单 → 风控 → 仓位管理 → 止损止盈
```

## 2. 安装指南

### 2.1 环境要求

- Python 3.11+
- Windows / macOS / Linux
- 网络连接（用于获取行情数据和 API 调用）

### 2.2 一键安装

```bash
# Windows
install.bat

# 跨平台
python install.py
```

安装脚本会自动：
1. 创建虚拟环境（可选）
2. 安装所有 Python 依赖
3. 检查 API Key 配置
4. 初始化数据目录

### 2.3 手动安装

```bash
pip install -r requirements.txt
```

### 2.4 API Key 配置

复制 `.env.example` 为 `.env`，填入你的 API Key：

```bash
# .env 文件

# Alpaca (美股模拟交易) — 必填
# 申请: https://app.alpaca.markets/
ALPACA_API_KEY=your_paper_trading_key
ALPACA_SECRET_KEY=your_paper_trading_secret
ALPACA_BASE_URL=https://paper-api.alpaca.markets/v2

# Finnhub (金融数据) — 必填
# 申请: https://finnhub.io/register
FINNHUB_API_KEY=your_finnhub_key

# LLM (可选, 用于自然语言交互)
# 支持 OpenAI 兼容 API (如 DeepSeek, 通义千问等)
LLM_MYMODEL_ENDPOINT=https://api.example.com/v1
LLM_MYMODEL_API_KEY=sk-your-api-key
LLM_MYMODEL_MODEL=your-model-name
LLM_DEFAULT=mymodel
```

> 💡 **不配置 LLM？** 系统会自动降级到关键词规则引擎，所有功能仍可使用，只是对话不够智能。

## 4. 功能详解

### 4.1 智能选股 🎯

用自然语言选股，系统自动解析参数 → 全美股扫描 → 多维度评分 → LLM 辅助判断。

**使用方式：**
- 对话输入："帮我选5支10美元的潜力股"
- 对话输入："选3只20-50美元的科技股"
- 仪表盘：🎯 智能选股页面

**评分维度（四维加权）：**

| 维度 | 权重 | 指标 |
|------|------|------|
| 技术面 | 25% | RSI、均线比率、量比 |
| 基本面 | 30% | P/E、分析师推荐、营收增长 |
| 情绪面 | 20% | 新闻关键词情绪分析 |
| 动量面 | 25% | 5日/20日收益率 |

**降级策略：**
- AKShare 不可用 → 使用扩展关注列表（80只覆盖各行业）
- Finnhub 不可用 → 跳过基本面/情绪评分
- LLM 不可用 → 纯评分排序 + 模板推荐理由

### 4.2 市场调研 🔍

自动扫描市场新闻，分析情绪，发现热点股票。

**流程：**
1. 获取 Finnhub 市场新闻 + 关注列表公司新闻
2. 关键词情绪分析（正面/负面/中性）
3. 统计新闻中提及的股票频率
4. 获取候选股票详情（公司概况、行业）
5. 生成小白友好的调研报告

### 4.3 策略生成 📈

从候选股票池自动生成交易策略。

**5个预置策略模板：**

| 模板 | 模型 | 风险 | 特点 |
|------|------|------|------|
| 稳健成长 | LightGBM | 🟢 低 | 大盘蓝筹，低换手 |
| 动量追踪 | LightGBM | 🔴 高 | 动量因子，中高频 |
| 价值挖掘 | Linear | 🟢 低 | 基本面因子，长期持有 |
| 科技先锋 | LSTM | 🔴 高 | 科技股池，深度学习 |
| 均衡配置 | LightGBM | 🟡 中 | 多因子均衡，适合大多数 |

**使用方式：**
- 仪表盘：📈 策略管理 → 从模板创建
- 编程接口：

```python
from src.engine.strategy_templates import strategy_templates

# 列出模板
templates = strategy_templates.list_templates()

# 从模板创建策略
strategy = strategy_templates.create_from_template("steady_growth")
```

### 4.4 回测验证 🧪

用历史数据验证策略效果。

**评级标准：**

| 评级 | 年化收益 | 夏普比率 | 最大回撤 |
|------|---------|---------|---------|
| A ⭐⭐⭐⭐⭐ | >20% | >1.5 | <10% |
| B ⭐⭐⭐⭐ | >15% | >1.0 | <15% |
| C ⭐⭐⭐ | >10% | >0.5 | <20% |
| D ⭐⭐ | 不达标 | — | — |

### 4.5 交易执行 💰

通过 Alpaca API 执行模拟交易。

**流程：**
1. 接收交易信号
2. 7条风控规则检查
3. 计算下单数量
4. 提交市价单
5. 更新持仓记录

### 4.6 风控系统 🛡️

7条风控规则，保护你的资金安全：

| 规则 | 默认值 | 说明 |
|------|--------|------|
| R1 单票最大仓位 | 30% | 防止重仓一只股票 |
| R2 最大持仓数 | 10只 | 分散风险 |
| R3 日最大亏损 | 5% | 触发后停止交易 |
| R4 总最大回撤 | 15% | 触发后暂停策略 |
| R5 单票止损 | -5% | 亏损自动卖出 |
| R6 日交易次数 | 20次 | 防止过度交易 |
| R7 模拟盘周期 | 30天 | 不满30天不允许实盘 |

### 4.7 工作流 🔄

三种自动化工作流：

| 工作流 | 触发 | 流程 |
|--------|------|------|
| 每日主循环 | 手动/定时 | 调研→策略→回测→执行→监控 |
| 策略迭代 | 手动/每周 | 回顾表现→优化因子→重新回测 |
| 紧急止损 | 手动/自动 | 告警→清仓→通知 |

### 4.8 LLM 智能对话 🧠

配置 LLM 后，系统获得 AI 智能对话能力：

- **意图识别**：理解你的自然语言意图
- **参数提取**：从对话中提取股票代码、价格、数量等
- **回复生成**：用通俗语言解释结果
- **多轮对话**：记住上下文，支持连续对话

**支持的 LLM 提供商（任何 OpenAI 兼容 API）：**
- DeepSeek
- 通义千问
- OpenAI GPT
- 其他兼容 API

## 6. 实盘迁移指南 (Phase 6 新增)

### 6.1 迁移流程

系统从模拟盘切换到实盘需要通过 **6 项安全预检**：

| # | 检查项 | 要求 |
|---|--------|------|
| 1 | Paper Trading 周期 | ≥ 30 天 |
| 2 | 策略质量 | 至少 1 个 A/B 级策略 |
| 3 | 风控告警 | 当前无告警 |
| 4 | 回撤控制 | 总回撤 < 10% |
| 5 | 交易频率 | 日交易次数合理 |
| 6 | API 配置 | Alpaca API Key 已配置 |

### 6.2 渐进式仓位

迁移成功后，系统不会立即全仓位运行，而是按周逐步放大：

| 阶段 | 仓位系数 | 说明 |
|------|---------|------|
| 第 1 周 | 50% | 半仓位试水 |
| 第 2 周 | 75% | 确认稳定后加仓 |
| 第 3 周 | 100% | 全仓位运行 |

### 6.3 操作步骤

1. **Dashboard 操作**: 进入「系统设置」->「实盘迁移管理」面板
2. **执行预检**: 点击「执行预检」按钮，确认 6 项全部通过
3. **确认迁移**: 点击「迁移到实盘」按钮，二次确认后执行
4. **监控运行**: 观察渐进式仓位系数变化
5. **紧急回滚**: 如有异常，点击「回滚到模拟盘」立即撤回

### 6.4 审计日志

所有迁移操作记录在 `data/migration_audit.json`，包含：
- 迁移时间、操作类型、模式切换记录
- 渐进式仓位参数
- 回滚记录

## 7. 多策略组合管理 (Phase 6 新增)

### 7.1 功能简介

多策略组合允许你同时运行多个策略，通过权重分配和信号聚合实现分散投资。

### 7.2 权重分配方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| **等权分配** | 每个策略相同权重 | 策略数量少、性能接近 |
| **风险平价** | 波动率低的策略权重更高 | 策略风险差异大 |
| **绩效加权** | 夏普比率高的策略权重更高 | 有回测数据、绩效差异明显 |

### 7.3 信号聚合规则

当多个策略对同一股票产生信号时：
- **同方向**: 信号增强，置信度提升
- **反方向冲突**: 按加权净方向决定（多数服从少数）
- **完全冲突** (等权 buy vs sell): 跳过该信号

### 7.4 操作步骤

1. **Dashboard 操作**: 进入「策略管理」->「多策略组合管理」
2. **创建组合**: 选择 ≥ 2 个策略，选择权重分配方式
3. **查看权重**: 饼图展示各策略权重分布
4. **重新分配**: 点击「重新分配权重」按最新绩效调整
5. **删除组合**: 不再需要的组合可以删除

## 8. 性能优化 (Phase 6 新增)

### 8.1 二级缓存

系统采用 L1 内存 + L2 磁盘的二级缓存架构：

| 层级 | 类型 | TTL | 用途 |
|------|------|-----|------|
| L1 | 内存 LRU | 5 分钟 | 行情数据快速访问 |
| L2 | Parquet 磁盘 | 12 小时 | 持久化行情缓存 |
| - | JSON 磁盘 | 30 分钟 | 新闻/情绪数据 |

### 8.2 并行回测

- 多策略回测使用 `ThreadPoolExecutor` 并行执行
- 默认 4 线程，可通过 `max_workers` 参数调整
- 结果按夏普比率降序排列

### 8.3 LSTM 深度学习模型

系统支持 LightGBM 和 LSTM 两种模型：
- **LightGBM**: 默认模型，快速高效，适合表格因子
- **LSTM**: 深度学习时序模型，适合捕捉序列模式（需安装 PyTorch）

## 9. FAQ 与故障排除

### Q: 启动后提示 "Alpaca 未配置"
**A:** 检查 `.env` 文件中 `ALPACA_API_KEY` 和 `ALPACA_SECRET_KEY` 是否填写正确。申请地址: https://app.alpaca.markets/

### Q: 启动后提示 "Finnhub 未配置"
**A:** 检查 `.env` 文件中 `FINNHUB_API_KEY` 是否填写。申请地址: https://finnhub.io/register

### Q: LLM 对话不智能 / 提示 "规则模式"
**A:** LLM 未配置或 Key 无效。在 `.env` 中配置 `LLM_*` 环境变量。不配置 LLM 也能使用所有功能，只是对话使用关键词匹配。

### Q: 选股结果为空
**A:** 可能原因：
1. 价格范围太窄，没有符合条件的股票
2. 网络连接问题导致数据获取失败
3. AKShare 接口临时不可用（系统会自动降级到关注列表）

### Q: 回测提示 "数据不足"
**A:** 需要先初始化 Qlib 数据：`python main.py init`

### Q: 交易被风控拦截
**A:** 检查风控规则：
- 单票仓位是否超过 30%？
- 持仓数量是否超过 10 只？
- 当日亏损是否超过 5%？
- 日交易次数是否超过 20 次？

### Q: 如何切换到实盘？
**A:** 推荐使用 Dashboard「系统设置」->「实盘迁移管理」面板操作。系统要求模拟盘运行满 30 天、至少 1 个 A/B 级策略等 6 项预检全部通过后才允许迁移。详见 [第 6 章](#6-实盘迁移指南-phase-6-新增)。

### Q: 仪表盘打不开
**A:** 确保已安装 Streamlit：`pip install streamlit`，然后运行 `streamlit run src/ui/dashboard.py`

### Q: 如何重置对话上下文？
**A:** 在对话中输入 `/reset` 或重启程序。

## 💡 使用建议

1. **先模拟盘**：始终先用 Paper Trading 模式，熟悉系统后再考虑实盘
2. **从模板开始**：不确定用什么策略？从「均衡配置」模板开始
3. **关注风控**：定期查看风控状态，确保没有触发警报
4. **分散投资**：不要把所有资金放在一只股票上
5. **持续学习**：查看调研报告和回测结果，理解策略为什么赚/亏

## ⚠️ 风险提示

- 本系统仅供学习和研究使用，**不构成投资建议**
- 过去的回测表现**不代表未来收益**
- 模拟盘交易不涉及真实资金，实盘交易有真实亏损风险
- 请充分了解风险后再做投资决策
